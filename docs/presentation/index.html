Stop here. Leave room for questions. One person should control the laptop, even if several teammates speak.

Short answers to likely questions

Does this use AI? Today’s search uses saved words and notes. AI recall and photo scanning have integration code, but live service setup is still pending.

Why not a normal contacts app? We keep the event and the conversation alongside the contact, then use that context to find the person later.

Is it private? A shared card exposes only selected fields. Notes belong to the person who saved them. This demo uses fictional data in a separate local workspace.

LinkedIn? We support manually entered profile links. We are not importing or scraping other people’s profiles.

Is it deployed? It runs locally for this check-in. A Supabase project exists; its live database connection and public hosting still need setup.

What feedback do you want? Was the flow clear? Which information would you save after meeting someone? Is adding a note quick enough?
